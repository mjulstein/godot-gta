# Ideas

This directory is for feature ideas that are not ready to become active user stories.

Use it for:

- rough gameplay concepts
- mission or objective sketches
- open questions
- constraints and risks that still need discovery
- candidate features that may later move into a numbered feature spec

Rules:

- Keep ideas in Markdown only
- Prefer one file per concept
- Treat these files as exploratory, not committed scope
- Move an idea into a numbered spec only when goals, acceptance, and sequencing are clear

Suggested file sections:

- Summary
- Why it might matter
- Player-facing loop
- Open questions
- Risks
- Promotion checklist

Seed files:

- [mission-loops.md](./mission-loops.md)
