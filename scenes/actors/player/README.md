# Player Scene

`player.tscn` is the controllable on-foot actor.

Responsibilities:

- collision shape
- visible placeholder body
- movement handled by `scripts/actors/player/player_controller.gd`

Future additions should stay focused on player-specific state, not global game orchestration.
